# Configuration Reference

`agent/settings.json` is a human-readable checklist, not an API payload.

| Setting | Value |
|---|---|
| Harness | GitHub Copilot |
| Model | Environment-default reasoning model |
| Memory | Disabled |
| Horizon | 3–12 months |
| Status | Draft / Preview only |
| Web grounding | Public web, policy permitting |
| External writes | None |

Attached skills: `uk-equity-evidence`, `human-reviewed-inputs`, `uk-market-signal`, `verified-market-chart`, and `approved-report-export`.
